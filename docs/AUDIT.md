# Ukaguzi (audit log)

Mfumo huhifadhi **nani alirekodi** mahudhurio na malipo.

## Miundo

- `Hudhurio.iliyorekodiwa_na` — User aliyerekodi safu
- `Malipo.iliyorekodiwa_na` — User aliyerekodi malipo (pamoja na `mpokeaji` wa Mwalimu)
- `RekodiUkaguzi` — historia ya kitendo (append-only)

## Mahali pa kuona

- App: `/madrasa/ukaguzi/` (Mkuu au ofisi yenye fees)
- Wasifu wa mwanafunzi → jedwali la malipo → safu **Alirekodi**
- Fomu ya mahudhurio ikiwa tayari yameshasajiliwa → “Yalirekodiwa na …”
- Django admin → Rekodi za ukaguzi
